# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project purpose

This is a personal study project for Unity ECS (DOTS). The user already knows the basics of ECS as it existed in **Unity 6.0**, and is using this project to learn what changed and what's new in **Unity 6.6** (`com.unity.entities` 6.6.0, Editor 6000.6.2f1) by building small experiments.

**Study log workflow — keep this up to date:**
- Whenever a difference from Unity 6.0 ECS, or a newly-learned 6.6 ECS concept, comes up, append a brief entry to [Study.md](Study.md) at the repo root (see the format described in that file).
- When explaining ECS concepts to the user in chat, default to **diff-focused explanations** (what changed vs. 6.0 ECS) rather than teaching the concept from scratch. Give a full/detailed explanation only when the user explicitly asks for it.

## Environment & tooling

- This is a Unity Editor project, not a CLI/npm-style repo — there are no build/lint/test scripts in the repo itself. All builds, Play Mode runs, and test runs happen through the Unity Editor (6000.6.2f1) or the Unity Editor MCP tools below.
- A **Unity Editor MCP server** (`mcp__unity-editor-mcp__*`) is available in Claude Code sessions for controlling a connected, running Unity Editor instance directly: creating/editing scripts and GameObjects, entering Play Mode, reading the console, and running tests. Prefer these tools over hand-editing `.unity`/`.asset`/`.prefab` YAML files when an Editor is connected.
  - Run tests with `run_tests` (EditMode/PlayMode via Unity Test Framework) rather than any CLI test runner — none is configured in this project.
- Package dependencies live in `Packages/manifest.json`; `Packages/packages-lock.json` is generated by Unity and should not be hand-edited. Add/remove packages via the Package Manager (or the `package_add`/`package_remove` MCP tools) so the lock file stays consistent.

## Key packages

From `Packages/manifest.json` — the ones relevant to ECS/DOTS work:
- `com.unity.entities` 6.6.0 — the ECS framework itself.
- `com.unity.entities.graphics` 6.6.0 — rendering entities (Entities Graphics / Hybrid Renderer successor).
- `com.unity.render-pipelines.universal` 17.6.0 — URP, used with the 2D renderer (`Assets/Settings/Renderer2D.asset`).
- `com.unity.timeline` 6.6.0, `com.unity.inputsystem` 1.20.0 — also present.
- Otherwise standard Unity 2D template packages (2D animation, tilemap, sprite, aseprite/psd importers, etc.).
